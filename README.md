# 薪資核算技能及案件保存套件

版本：2026.11.17.2。

本工具會自動保存本核算案件明確指定的薪資原始文件、計算結果、已綁定輪次的可見文字對話及執行診斷，於本機加密後同步至公司私有倉庫，供授權管理員按經辦人資、薪資人員及月份排查。

套件包含四個薪資技能、既有診斷及案件原件／結果／對話保存。更新 GitHub 不代表人資電腦已更新；需要安裝新版並重新啟動 Codex。

## 安裝與日常使用

人資使用管理員對應本機分發的專屬壓縮包；Windows 執行 `install.ps1`，macOS 執行 `install.sh`。成功後重新啟動 Codex。通用包先生成設備登記申請，由管理員登記後才可同步；專屬包不能多人共用或上傳公開倉庫。

人資照常提供月份、公司及實際文件，不必另說「幫我記錄」。助理按照[案件保存](skills/payroll-operations/references/case-archive.md)建立案件，綁定人員、明確來源與本輪對話，在各階段保存實際結果。日常不重複播報用途；安裝、保存或同步失敗仍如實標示待補。

可對 Codex 說：「請安裝這個完整套件，保留原有記錄與舊版備份；安裝後重啟 Codex，再依 payroll-operations 核算指定月份。」

需要 Python 3.10 以上、Git、OpenSSH、cryptography；實際核算仍需原表格依賴及辦公應用。對話保存另需相容的 Codex 應用服務；不支援時標示未完成，不拿摘要冒充對話。

## 管理員查看

公開倉庫只放程式、文檔、公開合成測試及加密公鑰。原件、計算結果、人員索引及對話在本機加密與設備簽名後才送到公司指定的私有倉庫；人資不持有管理員解密密鑰。

管理員每日下載到公司本機，核對簽章、密文及還原摘要後保留密文。執行 `管理员查看案件.ps1` 開啟本機限時頁面，按月份、薪資人員及經辦人資查案，選擇版本下載原件、結果和查看對話。頁面僅綁定 127.0.0.1、使用不可猜測的臨時入口，一小時後停止；下載會在管理員瀏覽器選定位置產生原件。

目前不自動刪除雲端或重寫 Git 歷史。每日 23:00 的歸檔需要本機排程具備執行條件；本機關機或排程未執行時不能保證準時。

## 覆蓋與限制

對話僅包含綁定輪次的使用者與助理可見文字；回覆進行中標成未完成並等待補存。未綁定的聊天、非文字內容及全部工具原始輸出不保證保存。原件與結果限本案明確指定及實際補存的文件，不掃描其他資料夾。

每案最多 128 份文件另加對話，單文件 32 MiB、原件產物合計 256 MiB，清單仍受 512 KiB 限制；超限不截斷冒充完整。完整執行方式、權限及未覆蓋項目見[公司記錄歸檔說明](公司记录归档说明.md)。
