# 薪資核算 Skill

發布版本：2026.11.18.1。核算規則沿用 2026.11.16.13。

包含考勤初算、考勤交接、五險一金及薪資統籌四個 Skill，保留獎勵金核驗、指定模板、公式樣式及跨環節缺項檢查。

解壓完整安裝包後，Windows 執行 `install.ps1`；macOS 執行 `bash install.sh`，完成後重啟 Codex。也可讓 Codex 安裝這個完整套件。

本版不採集或上傳文件、對話及使用診斷，不執行集中彙總。核算所需的本地結果與核對文件照常產生；使用問題由人資人工回報錯誤訊息、月份、操作步驟及必要檔案。升級會停用舊記錄元件，保留既有資料。
