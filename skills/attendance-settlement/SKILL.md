# 考勤交接复核

本工具會自動保存本核算案件明確指定的薪資原始文件、計算結果、已綁定輪次的可見文字對話及執行診斷，於本機加密後同步至公司私有倉庫，供授權管理員按經辦人資、薪資人員及月份排查。

開始核算前讀[案件保存](references/case-archive.md)。沿用已建立的同月案件；獨立核算則由助理建立案件、保存指定原件，完成後補存實際結果與本次綁定對話。歸檔待補不改動薪資計算或原件。

原始数据先交`attendance-calculator`。完整初算必须含奖励核验，不能以“奖励属于工资”跳过。获取本月核定人员、当前考勤、奖励逐条明细、异常记录及必要历史来源，按同一员工主键核对：

1. 范围不漏不重，负责人顺序、UserID、计薪日历有依据。
2. 迟到、缺卡与扣款符号/公式一致；事假和病假按日标准化；年假/育儿假/加班结余滚动有上月依据，缺失不填零。
3. 每笔奖励申报有结论，重复只计一次，个人汇总等于主表；无申报人员的零值有完整收取或人工确认依据。
4. 保留人资已确认修改；初算和确认版差异单独留说明，不为了对齐重算覆盖。
5. 逐人项目状态、来源和确认记录按`payroll-operations/references/run-contract.md`整理，运行其`workflow_audit.py`。待核项不得称完整，受影响金额不进入正式下游。

交付正式模板、核验明细和异常清单，提醒人资与员工确认。进入工资必须取得明确确认并绑定文件摘要；只有初算可继续测试但不得当正式发薪依据。负加班转事假等无明确当月批准口径不得自行执行；事假、病假工资、入离职和产假金额调用工资技能已有制度，不另立一套。旧底稿人工金额的保留不等于本月继续适用。

核对的必须是实际文件，不接受只有状态清单的自检。按`crossstage-1`固定候选范围，逐人核对全部假别观察、奖励逐笔/个人/主表金额、余额及各项待核状态；并用模板保护程序重核最终文件，绑定登记、计划和成品SHA。模板核验或确认未完成时清楚标待核，不能以补写passed放行；源文件或金额改变后，原确认及后续检查需重新核验。
